# ai-engineering-lab

A personal lab for studying AI engineering and documenting what I learn along the way.

## Purpose

This repository is where I explore how modern AI systems are designed and built. It brings together notes, experiments and small projects covering topics such as:

- AI architecture and system design
- LLM foundations
- Retrieval-Augmented Generation (RAG)
- Workflows and orchestration
- Agents

The goal is to build practical understanding through hands-on work and to keep a record of that learning as a portfolio.

## Status

This is a work in progress. The structure and content will grow and change as I study each topic.
